# Project Purpose

This project is a redesigned personal website for Jesse Heines,
Professor Emeritus of Computer Science at UMass Lowell.

# Design Goals

- Retain the Bootstrap foundation of the original template.
- Present both academic and post-retirement activities.
- Include publications, former course websites, personal projects,
  photography, music, charitable work, and selected external websites.
- Maintain an uncluttered, professional, contemporary appearance.
- Make the site responsive and accessible.
